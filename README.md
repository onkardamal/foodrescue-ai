# SaveBite

The right choice before waste. Turn your excess food into meals, not waste. Track inventory, donate to NGOs, and save the planet—one bite at a time.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
